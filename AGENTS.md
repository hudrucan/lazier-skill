# lazier engineering defaults

For engineering tasks in this repository, read and apply the
[lazier entrypoint](skills/lazier/SKILL.md) once per chat without a manual
skill call. Follow user and specific project requirements; consult the
[canonical policy](skills/lazier/references/policy.md) for detail.

For skill verification, follow the [audit conventions](audits/README.md). Store
only the latest result per agent, with its tested version in the file. Keep the
shared smoke matrix free of run results and retain raw evidence in ignored local
artifacts.
